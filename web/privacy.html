Privacy notice · Version 0.2.1 · October 16, 2026

Current account availability

The account integration is built, but registration is awaiting activation of the authentication service and verified email delivery. Until that happens, TomiTrack does not accept account credentials or upload collections. You can continue using the device collection and file backups.

What stays on your device

Your models, notes, prices, wishlist and photos are saved in local app storage (IndexedDB). Guest and signed-in account collections use separate storage. Light/dark appearance preferences are stored on this device. Local collection storage is not encrypted at rest; protect access to your device and keep backups. There are no advertising trackers or analytics.

Accounts when activated

Email/password authentication is provided by Supabase Auth over HTTPS. Your email address, password and optional display name are sent directly to that service when you submit registration or sign-in. TomiTrack does not write your password to files, browser storage or collection backups. Sessions remain in memory, so you sign in again after closing or restarting the app. Email verification and password recovery use codes sent by the configured email provider.

Private account backups

Once accounts are active, you may explicitly upload a collection backup, including photos, to your account. Backups are protected by owner-only database access rules. There is no automatic upload or live sync. Uploading replaces the previous cloud backup after confirmation; restoring replaces the current account collection after confirmation. The current upload limit is 10 MB.

Photos and file backups

You choose individual photos or backup files through the device file picker. Photos are resized before local storage. Exported JSON backups include your collection and photos; CSV exports contain text records only. Exports do not include passwords or session tokens. Anyone with a backup file can read it, so keep it somewhere you trust.

Connections and permissions

The website is hosted on GitHub Pages. GitHub processes ordinary site requests under its privacy policy, and the download page reads public GitHub release information. Opening external links contacts the destination website. Installed apps bundle the tracker for offline collection use. Android also contacts the public GitHub release API for update checks and downloads APKs from GitHub over HTTPS. Launch checks run at most once per day and can be disabled in Settings. No collection contents or account tokens are sent with update requests. APKs are cached privately; Android may ask you to allow installations from TomiTrack, then requires installation confirmation. Photo and backup access uses scoped file pickers, without camera or broad storage permissions.

Signing out and removing local data

Manual sign-out asks before removing the current account's local cache. Upload a cloud backup or export a file first to keep changes. The guest collection stays on the device. Removing a model deletes that local record and photo. Clearing app/browser storage or uninstalling Android deletes local collections. Windows uninstallers may retain data for updates. Cloud backups, once enabled, are separate from local storage and are not deleted when you uninstall; contact TomiKing for account/data deletion assistance.

Early access

Collection values are manual estimates. The starter catalog and generic illustrations demonstrate the workflow rather than verifying exact releases or variants. Live market prices and continuous synchronization are not provided.
