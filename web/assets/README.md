# TomiTrack app mark

The owner requested pink and yellow app branding for version 0.4.19. The existing T mark now uses pink `#ed6aa7` and yellow `#ffe36b`. The interface retains its established palette.

`mark.svg` is the vector source, used by the app/site headers and browser favicon. `icon.png` is the 512×512 transparent PNG rendered from that vector; Android preparation copies it to the launcher drawable, Electron and Windows packaging use it directly, and the PWA/Apple touch icon references it.

Manufacturer marks in `brands/` have separate provenance in that folder's README. Catalog photographs are source-hosted references with per-release attribution; no Matchbox source image bytes are bundled here.
