# TomiTrack 0.4.12 · Early access

Tomica Limited Vintage release pages now show compact green estimated-value and MSRP buttons above the photograph, with source/calculation details available on tap. Imported 1,680 positive official TOMYTEC list prices; four zero-price references remain unavailable. Japanese MSRP includes consumption tax and is shown in JPY.

Linked values prefer at least three recent confirmed comparable sales of the exact variant/condition. Where reliable sold data is unavailable, the owner-directed estimate is MSRP × 1.10 for every calendar year since release, converted to USD using the dated ECB reference rate. This formula is clearly labeled MSRP-based and does not establish market appreciation or adjust for condition. Current eBay evidence is insufficient for a three-sale average; no authenticated bulk sold-data feed is connected.

My garage includes Sync price data below App updates. Newly added priced TLV copies default to linked valuation; existing manual entries, purchase costs and editable fallback estimates are preserved. JSON backups retain valuation choice. Sync downloads the latest reviewed public snapshot; it does not query eBay live or upload your collection. Other brands remain manual.

All 17,920 catalog references, 4,268 English overlays, 2,450 photos and Android safe-area handling are preserved. Android code 18 uses the permanent signer. Physical upgrades/folding and Windows execution remain untested.
