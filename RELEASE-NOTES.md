TomiTrack 0.4.1 — clearer brands and catalog-first collecting.

- Browse brands through a two-column mobile grid with manufacturer marks, catalog counts and linked garage progress. Desktop uses four columns.
- Every Add model action opens catalog search. Choose a release, confirm it, then save your copy to the collection or wishlist. New free-form entries are disabled.
- Release identity stays attached to the selected catalog entry; condition, quantity, photo, inspected color/scale, prices, shelf and notes remain yours. Existing legacy entries and v1 backups remain supported.
- Same 17,920-record public catalog; all coverage remains partial. No catalog model photos or live pricing. Accounts still await activation.

Android retains the permanent signing identity and uses versionCode 7. Install over 0.2.1 or newer. Early 0.1/0.2 installs still require the documented one-time backup migration. Windows remains unsigned; physical device testing is outstanding.
