# TomiTrack 0.4.22 · Early access

Add 500 distinct Matchbox variant photos from 2013–2017, checked against their cited catalog variants using full-size source photographs. Matchbox now has 1,815 photo entries; all brands total 3,815. Existing photos, the pink-and-yellow logo and personal collection data are preserved. Catalog photos load online from source hosts with attribution.

Android package and permanent signing identity are unchanged; versionCode 28. Android APK, Windows installer, public catalog SQLite and checksums are included.
